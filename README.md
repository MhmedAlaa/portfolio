# Mohamed Alaa Saleh — Civil & BIM Engineering Portfolio

> موقع معرض أعمال هندسي حديث ومتجاوب بالكامل، يدعم اللغتين العربية والإنجليزية (Bilingual AR/EN)، ومبني خصيصاً للمكاتب الفنية وهندسة الـ BIM وحساب التكاليف والمناقصات.

---

## 📁 هيكلية المشروع الموحدة (Project Structure)

تم دمج وتوحيد المشروع في بنية نظيفة ومعيارية تسهل الصيانة والإضافة والتطوير المستقبلي:

```text
skills/Portfolio/
├── index.html                  # نقطة الدخول الرئيسية للموقع (Semantic HTML5 + SEO)
├── README.md                   # دليل تشغيل وتطوير المشروع
│
├── css/
│   ├── style.css               # التصميم الأساسي (نظام متغيرات CSS + دعم RTL كامل + تجاوب)
│   └── font-awesome.min.css    # الأيقونات
│
├── js/
│   ├── translations.js         # قاموس الترجمة ثنائي اللغة (عربي / إنجليزي)
│   └── main.js                 # المتحكم البرمجي (جلب البيانات، التصفية، الـ Lightbox، العدادات)
│
├── data/
│   ├── projects.json           # قاعدة بيانات المشاريع (سهلة الإضافة والتعديل)
│   └── bim.json                # قاعدة بيانات عينات ونماذج الـ BIM
│
├── assets/
│   ├── images/                 # الصور ونماذج الرندر ومخططات الـ BIM والشعارات
│   └── docs/                   # المخططات ونماذج السيرة الذاتية بصيغة PDF
│
└── _archive/                   # النسخ القديمة المحفوظة (Webpage و portfolio_old)
```

## 🛠️ كيف تطور وتعدل على المشروع بسهولة؟

### 1. إضافة أو تعديل مشروع جديد:
افتح الملف `data/projects.json` وأضف كائناً جديداً:
```json
{
  "name": "اسم المشروع الجديد",
  "type": "Residential Towers / Medical / Industrial",
  "role": "TO / BIM / Estimation",
  "impact": "الوفر المالي أو الأثر الهندسي المحقق",
  "thumb": "assets/images/your_image.jpg"
}
```

### 2. تعديل النصوص أو الترجمة:
افتح الملف `js/translations.js`:
- ستجد قسم `en` للإنجليزية وقسم `ar` للعربية. كل نص معرّف بمفتاح واضح يمكن تعديله مباشرة دون لمس الـ HTML.

### 3. تغيير التصميم أو الألوان:
افتح `css/style.css`، وفي أعلى الملف ستجد متغيرات الـ `:root` المسؤولة عن درجات الأزرق، الكحلي، التيل (Teal)، الظلال، واستدارة الحواف.

### 4. إضافة عينات BIM جديدة:
افتح `data/bim.json` وأضف تفاصيل النموذج واسم الصورة في `assets/images/`.
